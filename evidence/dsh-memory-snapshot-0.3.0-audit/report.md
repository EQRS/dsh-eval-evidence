## 二、任务契约与读数

- 机制：`apply(ctx, config)` → `ctx.systemPrompt.section({name:'memory-snapshot', order, interpolate:false, text:()=>…})`；`text` 是每次组装 prompt 时求值的 provider，读 `config.files`（文件或目录）。
- 8 项注入断言（fixture：SOUL/MEMORY/deep/大文件夹）：
  S1 记忆内容注入 ✅｜S2 单文件上限截断（3000 B，`…[已截断，原文 5017 字节…]`）✅｜S3 多次调用稳定 ✅｜S4 缺失文件容错 ✅｜S5 front matter 剥离 ✅｜S6 目录递归（dirDepth=2 命中深层）✅｜S7 新鲜度标注 ✅｜S8 模板插值关闭（`{{x}}` 不炸）✅
- **不装组**：无 section 注入（0/24）。
- 口径说明：这是「注入是否真的送达 prompt」的功能验证；**端到端任务成功率（模型能否用上）未测**。
