# 标准测评报告 · dsh-rss 0.7.0（能力五状态）

> 依据：工程协议手册 v1.1 §2（五状态）、§3（任务契约）、§6（快测/标准边界）、§13（证据）。
> 本件是**标准测评**，不是体验快测：有任务集、配对对照、预注册、区间与判定。
> 快测底稿（安装/构建/119 项测试/16 条探针）见 [测评报告_dsh-rss_v0.1.md](测评报告_dsh-rss_v0.1.md)。

## 一、结论

**真有用**（区间下界 24 > 正向门槛 12）。

| 项 | 值 |
|---|---|
| 判定 | **真有用** |
| 主要指标 D（配对正确差） | **24**（范围 [-24, 24]） |
| 95% bootstrap 区间 | **[24, 24]** |
| 区间半宽 | **0**（预注册门槛 ≤ 6，满足） |
| 模型 | `deepseek-flash`，temperature=0.7，seeds=[101,202,303] |
| 样本 | 8 场景 × 3 seed × 2 组 = 48 次基础运行 |
| 耗时 | 148 秒 |

## 二、任务契约

- **任务**：订阅状态操作，8 个场景（S1–S8）：添加 3 条、URL 大小写归一去重、分类、OPML 导入（2 合法 + 1 ftp）、添加后删除、同名查询、尾部斜杠差异、YAML 序列化往返。
- **判分器**：每个场景执行后断言最终订阅状态（条数 / URL 归一 / category / 同名条数 / YAML 条数）。
- **对照组**：
  - 装：把插件 `feeds.js` / `opml.js` 的函数包装成 5 个工具（add / remove / list / import_opml / export_yaml），真实执行；
  - 不装：不传工具，模型无状态操作能力。
- **状态独立**：每个场景、每次运行都从空订阅列表开始。

## 三、预注册（跑前冻结）

- 主要指标 D = Σ(场景内装组正确数 − 不装组正确数)，范围 [-24, 24]；
- a = 12、b = 6；精度门槛：区间半宽 ≤ 6；
- bootstrap 按场景重采样 B=10000，seed=20261019；
- 反作弊：不中途改 a/b/样本量。

## 七、遗留问题（必须与结论一起读）

1. **对照退化**：不装组没有状态工具，必然 0 分。本结论只说明「订阅管理任务需要该插件」，**不代表解析质量优于裸模型**；
2. 单模型、单温度、8 场景刚达协议建议下限；
3. 未做独立复核（协议 §2.5 进榜要求）。

## 八、不适用条件

- 不适用于其它模型/温度/题集；
- 不适用于解析质量对比（本件未测）；
- 不适用于宿主内 `rss_*` 工具 UI、真实网络抓取、定时汇总；
- 不能据此宣称安全性（未做六威胁专项）。
